---
description: Проверить состояние чат-сервера (GET /health)
---

Проверь состояние сервера:

1. Выполни `curl -s http://localhost:${PORT:-8080}/health`.
2. Выведи понятное резюме:
   - сервер запущен / не запущен;
   - LLM включена (`llmEnabled: true`) или нет — при `false` не задан `DEEPSEEK_API_KEY`;
   - порт (`PORT`, по умолчанию 8080) и каталог истории (`CHAT_HISTORY_DIR`, по умолчанию `chat-history` в корне проекта).
3. Если сервер не отвечает — предложи `/chat-start`.
