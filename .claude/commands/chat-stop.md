---
description: Остановить запущенный чат-сервер
---

Останови сервер приложения:

1. Найди PID процесса, слушающего порт `${PORT:-8080}`:
   ```bash
   netstat -ano | grep LISTENING | grep ":${PORT:-8080}"
   ```
   PID — последнее число в строке.
2. Убей процесс (в Git Bash нужны двойные слэши, иначе MSYS превратит флаги в пути):
   ```bash
   taskkill //F //PID <pid>
   ```
3. Если процесс не найден — сервер уже остановлен, просто скажи об этом.
4. Если сервер запускался как фоновая задача в этой сессии — останови её через TaskStop.
5. Подтверди остановку: `curl -s http://localhost:8080/health` должен перестать отвечать.
