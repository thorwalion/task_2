---
description: Собрать и запустить чат-сервер (Ktor + Koog) в фоне
---

Запусти сервер приложения (рабочий каталог — корень проекта):

1. Проверь ключ API: `echo ${DEEPSEEK_API_KEY:+set}`. Если не задан — предупреди, что `/chat` будет отвечать 503, но сервер и остальные маршруты заработают.
2. Проверь, не запущен ли уже сервер: `curl -s http://localhost:${PORT:-8080}/health`. Если отвечает — сообщи об этом и остановись.
3. Запусти сервер в фоне (Bash с `run_in_background: true`), логи — в файл:
   ```bash
   gradle run > chat-server.log 2>&1
   ```
4. Дождись готовности: опрашивай `curl -s http://localhost:8080/health`, пока не вернётся `{"status":"ok",...}`. Первый запуск долгий (скачивание зависимостей) — жди до ~90 секунд; если нет ответа, прочитай `chat-server.log` и сообщи об ошибке.
5. Сообщи итог: порт, статус LLM из `/health`, что логи пишутся в `chat-server.log` и как остановить сервер (`/chat-stop`).
