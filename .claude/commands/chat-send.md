---
description: Отправить сообщение ЛЛМ в чат (POST /chat)
argument-hint: [сообщение]
---

Отправь сообщение ЛЛМ через API сервера.

- Текст сообщения — `$ARGUMENTS`. Если пусто — спроси у пользователя, что отправить.
- `conversationId` — по умолчанию `default`; если в `$ARGUMENTS` есть фрагмент вида `id=<слово>`, используй его как conversationId и убери из текста сообщения.
- Выполни:
  1. Запиши JSON-пейлоад в UTF-8 файл (инструментом Write, например `.claude/tmp/chat-send.json`):
     `{"conversationId":"<id>","message":"<сообщение>"}`
     ВАЖНО: не передавай кириллицу инлайном в `-d '...'` — Git Bash на Windows отправляет её в cp866, сервер получит кракозябры.
  2. Отправь файл:
     ```bash
     curl -s -X POST http://localhost:${PORT:-8080}/chat \
       -H "Content-Type: application/json" \
       --data-binary @.claude/tmp/chat-send.json
     ```
- Покажи пользователю ответ ЛЛМ (`reply`) и число сообщений в `history`.
- Если ответ 503 — объясни, что не задан `DEEPSEEK_API_KEY` (исправление: задать переменную окружения и перезапустить сервер).
- Если сервер не отвечает — предложи `/chat-start`.
- Весь LLM-трафик запроса пишется в `chat-server.log` (логгеры `[CHAT]` и `[LLM]`) — при желании покажи ключевые строки из лога.
